# Assumptions awaiting review

The initial four directions follow the four documented policy hooks, with one
slot each. Site observations and fast-tier gaps suggest questions, not known
mechanisms or predicted gains. The operator must review this allocation and the
brief before launching.

The service's public default quotas, delay and sample count are the draft
settings. A deployment with different approved knobs must update its declaration
and charter consistently rather than silently changing the judge.

Source trust, definition readers, isolation and machine-hour accounting are not
approved. No API concurrency or rate limit is assumed. The deployment retains
the existing user-configured model for every role.

This folder authorizes no run, pilot or comparison. A feedback run needs an
explicit operator-approved configuration; an H1 comparison additionally needs
the maintainer's preregistration. Keep this version unsigned.
